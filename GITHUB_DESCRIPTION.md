## Full Repository Description (for README or About section):

**Fire Detection and Prevention Backend**

A comprehensive FastAPI-based backend system for fire detection and prevention with MQTT integration for hardware devices (sensors, cameras, fire suppression arm), AI model integration for risk detection and fire location, real-time notifications, live video streaming, and a complete REST API for management.

**Key Features:**
- 🔥 Real-time fire detection and monitoring
- 📡 MQTT integration for hardware devices
- 🤖 AI model integration (risk detection & fire location)
- 📹 Live video streaming support
- 🔔 Real-time notifications
- 🔐 JWT-based authentication
- 🗄️ PostgreSQL database with SQLModel ORM
- 🚀 RESTful API for management website

**Tech Stack:**
- FastAPI, SQLModel, PostgreSQL
- MQTT (paho-mqtt), Serial communication
- JWT authentication, bcrypt password hashing
- Docker support, ready for deployment
